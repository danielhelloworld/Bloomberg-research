1. 每次首先从 GitHub 获取 main 的最新提交和旧报告，记录基准提交SHA。读取AGENTS.md、latest.json、index.html、最近实际每日更新，以及reports/2026-10-25/expanded_research.json、reports/2026-10-25/aggressive/attack_research.json、两份CONTINUATION.md和相关个股/来源。完整研究池为既有71家公司；不得只看摘要或把旧预案当新结果。新任务以本文件为准，忽略历史报告中已过期的本地调度指令。

2. 使用当时可合法获取的最新市场数据，更新美国大盘、市场宽度/行业与因子表现、利率曲线/美元/信用/波动率、能源/黄金及重要全球市场的背景；更新71股的行情与事件筛查，优先深挖当日预选、临近财报、重大披露或判断改变的公司。周末和休市日仍运行，但明确休市、沿用的交易日和报价时点，重点复核新闻、事件和下一交易日预案，不制造新交易日价格。对于无法访问的数据，仅保留标注过期的旧值或null，并写出具体缺口。

3. 所有行情记录来源、获取时间、数据自身时间与交易时段。前一完整常规时段收盘、盘前价、盘后价分别列示。财报/电话会的预定时间和已公布结果分开，使用时区数据库处理美东夏令时。公司事实优先IR/SEC，宏观优先官方发布。重核现金流、资本开支、SBC、一次性收益和估值分母；事实、分析判断与假设情景分别标示，保留可点击来源。历史不足时不得编造技术指标、相关性、预期收益、目标价或回测。
