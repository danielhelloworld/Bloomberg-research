## 数据与历史边界

2026-10-25 导入此前对话的完整207文件研究包，包含110个HTML页面及结构化数据、来源、计算和验证脚本。SHA-256校验清单见 `baseline-manifest.json`。原始研究包未包含平台账号、会话或发布客户端。

导入是归档，不是行情刷新。主要报价截至2026-10-23美股常规交易时段收盘，具体以各文件字段为准；10月26—30日页面是事前预案，不是已发生的结果。原研究文件内的本机路径、旧调度及复现说明仅为历史记录；当前每日工作以根目录AGENTS.md和.automation/daily-update.md为准。

研究候选不等于持仓。比赛WLS/证券资格、实际持仓及净值未核验；不下单、不改投资账户。历史和情景计算不构成收益或损失上限保证。
